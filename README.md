# 🧪 Laboratorio 1

**Fecha:** 25/08/2026

## 📚 Contenido del Repositorio

En este laboratorio se desarrollaron diferentes ejercicios utilizando C# y Windows Forms, con el objetivo de practicar el uso de controles, estructuras condicionales y operaciones básicas dentro de aplicaciones de escritorio.

El laboratorio está compuesto por tres ejercicios:

* 🖥️ **Práctica 1** - Controles
* 💰 **Práctica 2** - Descuento
* ➗ **Práctica 3** - Estructura If

---

## 🛠️ Tecnologías Utilizadas

* 💻 **Lenguaje:** C#
* 🧩 **Framework:** .NET Framework
* 🖥️ **IDE:** Visual Studio
* 🪟 **Interfaz:** Windows Forms
* 📦 **Control de versiones:** Git & GitHub

## 📸 Capturas de Pantalla y Problemas

### 🖥️ Problema 1: Controles

En este ejercicio se desarrolló una aplicación utilizando controles de Windows Forms para ingresar una fecha mediante los campos correspondientes.

La aplicación permite ingresar:

* 📅 **Día**
* 📅 **Mes**
* 📅 **Año**

Posteriormente, la información ingresada se muestra como una fecha.

### 💰 Problema 2: Descuento

En este ejercicio se desarrolló una aplicación que permite calcular el descuento aplicado a un valor de venta.

La aplicación determina el porcentaje de descuento dependiendo del valor ingresado y muestra:

* 💵 **Valor de venta**
* 💲 **Descuento en dólares**
* 📊 **Porcentaje de descuento**
* 🧾 **Venta final**

También se incluyen botones para calcular, limpiar los datos y salir de la aplicación.

### ➗ Problema 3: Estructura If

En este ejercicio se implementaron estructuras condicionales `if` y `else if` para realizar diferentes operaciones matemáticas.

El usuario puede seleccionar entre:

* ➕ **Suma**
* ➖ **Resta**
* ✖️ **Multiplicación**
* ➗ **División**

La aplicación muestra el signo de la operación seleccionada y posteriormente calcula el resultado.
